1. 제품 개요
ㅡ제품명: MY-SPENDING-APP

목적: 사용자의 소비 습관을 시각화하고, 예산 대비 지출 현황을 직관적으로 관리하여 계획적인 금융 생활을 돕는 웹 서비스입니다.

타겟: 대학생 및 사회초년생 등 간편하고 직관적인 지출 추적을 원하는 개인 사용자 혹은 돈을 너무 많이 쓰는 사람들

2. 주요 기능 (Key Features)

2.1 회원가입 및 로그인
ㄴ사용자는 계정을 생성하고 로그인할 수 있어야 한다.

요구사항
ㄴ이메일 / 비밀번호 기반 회원가입
ㄴ로그인 / 로그아웃 기능


2.2 소비 내역 기록 및 카테고리 분류
ㄴ사용자가 지출을 입력하면 카테고리별로 자동/수동 분류

요구사항
ㄴ금액, 날짜, 카테고리 입력
ㄴ카테고리 예시: 식비 / 교통 / 쇼핑 / 기타
ㄴ수정 및 삭제 가능


2.3 소비 통계 및 시각화
ㄴ소비 데이터를 그래프로 보여줌

요구사항
ㄴ카테고리별 파이차트
ㄴ월별 소비 그래프
ㄴ총 지출 요약


2.4 사용 가능 금액 계산 기능
ㄴ사용자의 예산 대비 남은 금액을 계산

요구사항
ㄴ월 예산 설정
ㄴ현재까지 사용 금액 표시
ㄴ남은 금액 자동 계산


2.5 캘린더 기반 소비 기록
ㄴ날짜별 소비 내역을 캘린더에 표시

요구사항
ㄴ날짜 클릭 시 상세 내역 확인
ㄴ하루 총 소비 금액 표시


2.6 카테고리별 월 예산 제한
ㄴ카테고리마다 사용할 금액 제한 설정

요구사항
ㄴ카테고리별 예산 설정
ㄴ초과 시 알림 표시


2.7 소비 실시간 표시 및 경고
ㄴ소비 입력 시 즉시 반영

요구사항
ㄴ일정 금액 초과 시 색상 변경
	ㄴ정상: 기본 색(예정)
	ㄴ초과: 빨간색 표시(예정)
ㄴ알림 또는 강조 UI 제공


2.8 저축 관리 기능
ㄴ사용자의 저축 목표 및 현재 저축액 관리

요구사항
ㄴ목표 금액 설정
ㄴ현재 저축액 표시
ㄴ진행률 표시 (Progress bar)


3. 기술 스택 (Tech Stack)

Frontend: HTML, CSS3, JavaScript
Backend: Python Flask, Supabase
Design: 사용자가 보기 쉽게 하기위해 검은색과 흰색을 위주로 사용한 디자인 (예정)

4. 핵심 가치 (Value Proposition)
직관적인 색상 알림: 단순히 숫자를 보여주는 것을 넘어, 날짜에 맞는 소비 기준을 적용해 사용자에게 즉각적인 심리적 가이드를 제공합니다.

간편한 기록: 복잡한 절차 없이 카테고리와 금액만으로 빠르게 지출을 관리할 수 있습니다.


5. 향후 확장 기능
ㄴ Ai 소비 분석 및 추천
ㄴ 자동 소비 분류 (카드 연동)
ㄴ 친구와 소비 비교 기능
ㄴ 알림 (푸시 / 이메일)
